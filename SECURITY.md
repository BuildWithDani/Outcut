# Security Policy

## Supported versions

Security fixes for Outcut AI are applied on the default branch of https://github.com/BuildWithDani/Outcut.

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories for this repository:

https://github.com/BuildWithDani/Outcut/security/advisories/new

If that is unavailable, open a private contact path via https://github.com/BuildWithDani and do not file a public issue with exploit details.

Include:

- Affected platform (Windows / macOS / Linux)
- Outcut AI version or commit SHA
- Steps to reproduce
- Impact assessment

We will acknowledge reports as quickly as practical and coordinate disclosure after a fix is available.

## Scope notes

Outcut AI is derived from Recordly. Vulnerabilities that also affect upstream Recordly may be disclosed upstream at https://github.com/webadderallorg/Recordly after Outcut users are protected, when appropriate.
