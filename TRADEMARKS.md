This page explains how to use them.

| ✅ You may | 🚫 You may not |
| --- | --- |
| Refer to Outcut AI factually, for example when describing compatibility, a fork, or attribution | Imply that BuildWithDani endorses your project without permission |
| Redistribute the unmodified logo with AGPL-compliant copies of this project | Use the Outcut AI logo as the main mark of a different product |
| Fork the code under the AGPL, as long as your fork is clearly labeled as a fork | Present a modified build as an official Outcut AI release |

These rules only limit how the brand identifies products. They never take away any right the software license gives you.
